# Atlas

Explore countries, regions, and Bangladesh's 64 districts on an interactive map. Mark places visited; progress is saved in your browser. The optional satellite layer needs an internet connection.

**Website:** https://mdrabbiahsankhanrajin.github.io/z-map-site/

This repository contains only the deployable static website. It has no development source, accounts, or server-side user database. The site is published from the root of `main` with GitHub Pages.
